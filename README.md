# RTMP Broadcaster

A minimal React Native (bare workflow) live-streaming app that publishes an RTMP stream from the device camera.

## Stack

| | |
|---|---|
| Runtime | React Native 0.73 (bare workflow, old architecture) |
| Language | TypeScript |
| RTMP | `react-native-rtmp-publisher` 0.4.7 |
| Android native | `rtmp-rtsp-stream-client-java` (bundled by library) |
| iOS native | `HaishinKit.swift` 1.2.7 (bundled by library) |

## Setup

### Step 1 — Clone / download this project

```bash
git clone <repo-url> rtmp-broadcaster
cd rtmp-broadcaster
```

### Step 2 — Scaffold the native shell with react-native init

Because `.xcodeproj` (iOS) and the Gradle wrapper JAR (Android) are
generated artifacts, run `react-native init` **into a temporary directory**
and copy only the missing native scaffolding back:

```bash
# Generate a fresh bare project alongside this one
npx react-native@0.73 init RTMPBroadcasterShell \
    --version 0.73.6 \
    --directory ../RTMPBroadcasterShell \
    --skip-install

# Copy the Xcode project (iOS only — Android gradle wrapper is already present)
cp -r ../RTMPBroadcasterShell/ios/RTMPBroadcaster.xcodeproj  ios/
cp -r ../RTMPBroadcasterShell/ios/RTMPBroadcaster.xcworkspace ios/   # created after pod install

# Copy the Gradle wrapper JAR
cp ../RTMPBroadcasterShell/android/gradle/wrapper/gradle-wrapper.jar \
   android/gradle/wrapper/

# Copy mipmap launcher icons (optional — replace with your own)
cp -r ../RTMPBroadcasterShell/android/app/src/main/res/mipmap-* \
      android/app/src/main/res/

# Copy the drawable needed by styles.xml
cp ../RTMPBroadcasterShell/android/app/src/main/res/drawable/rn_edit_text_material.xml \
   android/app/src/main/res/drawable/

# Clean up the scaffold
rm -rf ../RTMPBroadcasterShell
```

### Step 3 — Install JavaScript dependencies

```bash
npm install
```

### Step 4 — iOS: install CocoaPods

```bash
cd ios && pod install && cd ..
```

Expected output includes `Installing react-native-rtmp-publisher (0.4.7)`.

### Step 5 — Android: generate a debug keystore (first run only)

```bash
keytool -genkeypair -v \
  -storetype PKCS12 \
  -keystore android/app/debug.keystore \
  -storepass android \
  -alias androiddebugkey \
  -keypass android \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000 \
  -dname "CN=Android Debug,O=Android,C=US"
```

## Running the app

### iOS

```bash
npx react-native run-ios
```

To pick a specific simulator:

```bash
npx react-native run-ios --simulator "iPhone 15 Pro"
```

> **Camera note:** The camera preview does **not** work in the iOS Simulator.
> Run on a physical device (`--device "My iPhone"`) to test streaming.

### Android

1. Start an emulator or connect a physical device.
2. Run:

```bash
npx react-native run-android
```

## Deep link

Open the app pre-filled with RTMP URL and stream key:

```
livestream://stream?url=rtmp%3A%2F%2Fa.rtmp.youtube.com%2Flive2&key=YOUR-STREAM-KEY
```

**Android — test from adb:**

```bash
adb shell am start \
  -a android.intent.action.VIEW \
  -d "livestream://stream?url=rtmp%3A%2F%2Fa.rtmp.youtube.com%2Flive2&key=YOUR-KEY" \
  com.rtmpbroadcaster
```

**iOS — test from terminal (Simulator):**

```bash
xcrun simctl openurl booted \
  "livestream://stream?url=rtmp%3A%2F%2Fa.rtmp.youtube.com%2Flive2&key=YOUR-KEY"
```

## Streaming to YouTube Live

1. Go to [YouTube Studio → Live](https://studio.youtube.com/).
2. Copy the **Stream URL** (e.g. `rtmp://a.rtmp.youtube.com/live2`) and the **Stream Key**.
3. Paste them into the app inputs (or use the deep link above).
4. Tap **⏺ Go Live**.

## Key native configuration notes

### Android — `gradle.properties`

```properties
newArchEnabled=false   # react-native-rtmp-publisher requires old (Paper) architecture
hermesEnabled=true
```

### Android — `AndroidManifest.xml`

```xml
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.BLUETOOTH_CONNECT" />
<!-- cleartext RTMP traffic -->
android:usesCleartextTraffic="true"
```

### iOS — `Info.plist`

```xml
<key>NSCameraUsageDescription</key>
<string>Camera access is required to capture and stream live video.</string>
<key>NSMicrophoneUsageDescription</key>
<string>Microphone access is required to capture audio for the live stream.</string>
<key>NSAllowsArbitraryLoads</key>
<true/>   <!-- RTMP is cleartext -->
```

### iOS — `AppDelegate.mm`

The `AVAudioSession` is configured to `PlayAndRecord` / `VoiceChat` mode on
launch. This is required by HaishinKit (the underlying iOS RTMP library) so
the microphone works alongside the camera preview.

## Troubleshooting

| Problem | Fix |
|---|---|
| **iOS build fails: `RTMPPublisher` not found** | Run `pod install` again inside `ios/` |
| **Android build fails: duplicate class** | Add `android.enableJetifier=true` to `gradle.properties` (already set) |
| **Black camera preview on Android** | Accept camera + microphone permissions when prompted at launch |
| **Stream connects then immediately disconnects** | Verify the RTMP URL includes the application name (e.g. `/live2`) and the key is correct |
| **`newArchEnabled=true` crash** | `react-native-rtmp-publisher` 0.4.7 is old-arch only. Keep `newArchEnabled=false` |
